# RALPLAN R2 계획 수정본 (revision, stage_n=2)

근거: GAME_DESIGN.md v0 (dee3e88), stage-01-planner.md, stage-01-intent.md.
이 문서는 계획이다. 코드는 쓰지 않는다. 기획서 수정은 이 계획이 승인된 뒤에 한다.

## RALPLAN-DR 요약

### 원칙
1. 기획서 숫자는 바꾸지 않는다. 바꿀 것은 기획서를 먼저 고친다 (AGENTS.md).
2. 턴제: 유령 한 칸 = 경비병 한 칸. 실시간은 60초 시계뿐이다.
3. 로직은 canvas를 모르는 순수 함수 (src/logic.js).
4. 수용 기준은 브라우저에서 사람이 yes/no로 답할 수 있어야 한다.

### 결정 동인
1. 확정된 2장 규칙과 충돌하지 않을 것.
2. HUD는 캔버스 밖에 둔다. 320x240과 5장 레이아웃은 그대로.
3. R2에서 기획서 3장 흐름 (시작 → 게임 → 승리·패배 → 다시 시작·처음으로)을 채울 것.

### 선택지
- A. 턴제 경비병 (확정): 유령 한 칸 이동 시 경비병도 정확히 한 칸. 판정이 결정적이라 기대값을 기획서 숫자에서 적을 수 있다.
- B. 실시간 경비병: 기각. 2장 턴제 규칙과 충돌.

## 확정 결정 (사용자 응답)
- HUD: 캔버스 밖 HTML 텍스트 (타이머, 켜진 촛불 수).
- 화면 흐름: 시작 화면 포함. 승리·패배 화면에 "다시 시작" + "처음으로".
- 시간 초과 점수: 그때 켜진 촛불 수. 기획서 2장에 점수 규칙 추가.
- 경비병: 유령 한 칸 = 경비병 한 칸.
- 경비병 시야: 순찰 경로의 진행 방향을 따른다.

## 미확인 기본값 (검토에서 뒤집힐 수 있음)
- 벽은 시야를 막는다. 시야 칸이 벽이면 칠하지 않는다.
- 판정 순서: 유령이 먼저 이동, 도착 칸에서 시야 판정. 같은 칸 또는 인접 칸 판정은 도착 칸 기준.
- 수용 기준 번호: AC-x.y.

## 범위

### 공통: 화면 흐름 (기획서 3장에 채움)
- 시작 화면 → [시작] → 게임 (레이아웃 1) → 승리 또는 패배 화면.
- 승리·패배 화면: "다시 시작" (게임 재시작), "처음으로" (시작 화면).
- 레이아웃 1 승리가 최종 승리다. R2에서 레이아웃 2·3은 만들지 않는다.

### goal-2: 목표물·위협·타이머
- 촛불 12개를 레이아웃 1에 그린다. 꺼짐 #f2e6b0, 켜짐 #ffcc33. 유령이 밟으면 즉시 켜지고 되돌아가지 않는다.
- 경비병 G(9열 14행)에서 고정 순찰 경로 8~12칸을 반복한다. 매 판 동일.
- 경비병 시야: 진행 방향 앞 1칸, #8888aa. 벽이면 칠하지 않는다.
- 60초 카운트다운, 실시간, 입력 없이 계속 줄어든다. 표시는 캔버스 밖 HTML.
- 촛불 켜진 수를 캔버스 밖 HTML에 표시한다.

### goal-3: 승패와 화면 전환
- 승리: 촛불 12개 모두 켜짐.
- 패배: 유령이 시야 칸에 도착한 순간 즉시. 또는 60초 종료.
- 점수: 패배 화면에 "켜진 촛불 N/12" 표시.
- 화면 전환은 위 공통 흐름을 따른다.

## 수용 기준 (9장에 채움)

goal-2 완료 조건:
- AC-2.1: `python3 -m http.server 8000` 후 `http://localhost:8000/` 를 열면 촛불 12개가 #f2e6b0 색으로 보인다.
- AC-2.2: 유령을 촛불 칸에 옮기면 그 칸이 #ffcc33 색으로 바뀌고, 다시 밟아도 색이 되돌아가지 않는다.
- AC-2.3: 유령이 한 칸 움직일 때마다 화면 속 경비병도 정확히 한 칸 움직인다.
- AC-2.4: 경비병 바로 앞 1칸이 #8888aa 색으로 칠해지고, 경비병이 방향을 바꾸면 그 칸도 따라 바뀐다. 벽 칸은 칠해지지 않는다.
- AC-2.5: 캔버스 밖 타이머가 1초마다 1씩 줄어들고, 입력이 없어도 계속 줄어든다.

goal-3 완료 조건:
- AC-3.1: 유령을 경비병 시야 칸으로 옮기면 즉시 패배 화면이 뜬다.
- AC-3.2: 촛불 12개를 모두 밟으면 승리 화면이 뜬다.
- AC-3.3: 60초가 지나면 패배 화면이 뜬다. 패배 화면에 켜진 촛불 수가 적혀 있다.
- AC-3.4: 시작 화면에서 [시작]을 누르면 게임이 시작된다.
- AC-3.5: 승리·패배 화면에서 "다시 시작"을 누르면 레이아웃 1이 처음 상태 (유령 S, 경비병 G, 타이머 60, 촛불 0)로 돌아간다. "처음으로"를 누르면 시작 화면이 뜬다.

## 검증 계획
- 단위 (src/logic.js): 촛불 점화, 시야 칸 계산(벽 제외), 경비병 한 칸 이동, 순찰 방향 따라 시야 회전, 타이머 감소, 판정 순서, 승·패 판정. 기대값은 위 AC와 기획서 숫자에서 가져온다.
- 수동: 위 AC 번호를 `python3 -m http.server 8000`으로 띄운 브라우저에서 사람이 확인. fixture 스크린샷은 증거가 아니다 (AGENTS.md).
